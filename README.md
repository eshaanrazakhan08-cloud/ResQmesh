
# ResQMesh

### Team ASTRYX

An offline-first emergency communication system designed to help emergency messages reach authorized responders through connected gateways.

## Project Modules

- Frontend: Authority Dashboard (React + Vite)
- Backend: Supabase integration
- Android: ResQMesh mobile application

|---|---|

| Member 2 | Backend & Supabase |
| Member 3 | Android Application |

## Development Status

Currently under development.

## Important

The Authority Dashboard receives SOS incidents through the backend after they reach an internet-connected ResQMesh gateway.
